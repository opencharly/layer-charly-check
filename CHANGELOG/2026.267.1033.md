# 2026.267.1033 — docs(skill): jetkvm skill — wake-host, the no-signal hint, and auth repair

## Summary

Updates the `jetkvm-skill` entity — the source of the `jetkvm` skill in the
marketplace corpus — to match the plugin's surface. This is a PURE
documentation-only change: the ONLY file touched is `charly.yml`, and the only

new sections). The schema `version:` stamp is UNCHANGED from `main`.

### The documented method surface (all newly documented)

- **`ocr`** (read-only, no gate) — capture a frame, OCR it, assert `text` is
  present. Added to the read-only method list and to the new
  `## Screen reading — ocr and artifact_contains_text` section, alongside the
  `artifact_contains_text` validator (the wait-for-screen primitive in
  `screenshot` form).
- **`install`** (mutating, `allow_control`) — the configurable console-installer
  driver, documented in the new
  `## The configurable console-installer driver — install + kind: jetkvm` section:
  it connects once and walks an ordered `steps:` recipe, OCR-waiting each screen;
  the recipe is DATA supplied by a `kind: jetkvm` device entity; answers merge from
  `answers_env` / `answer_secrets` / `answers`; and the "NOT a backup — a console
  installer wipes a disk" operator-action rule.
- **`wake-host`** (mutating) — added to the method list, with the wake-host-vs-`wol`
  distinction (HID wake report for a display-asleep host; magic packet for a
  powered-off host) and the no-signal screenshot hint that names both.
- **`charly-jetkvm auth`** — the `## Running charly ON the device` section now
  documents the repair (mint a missing `local_auth_token` over ssh, never
  overwriting an existing one) and `env --heal`.
- **`triggers:`** gains the `kind: jetkvm` device-entity / `install` method /
  console-installer-recipe / wait-for-screen-OCR line, and the **`description:`**
  gains "OCR screen-reading" and "a CONFIGURABLE console-installer driver for a
  `kind: jetkvm` device".
- The `## The raw escape hatch — rpc` section is refreshed (the `rpc` safety gate).
